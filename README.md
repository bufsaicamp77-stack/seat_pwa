# 강의실 좌석 예약·출석 (PWA)

휴대폰 홈 화면에 앱처럼 설치할 수 있는 버전입니다.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면 (좌석 예약·출석 확인 시제품) |
| `manifest.webmanifest` | 앱 이름, 아이콘, 색 등 설치 정보 |
| `sw.js` | 서비스 워커: 앱 화면을 기기에 저장해 오프라인에서도 열리게 함 |
| `icons/` | 앱 아이콘 (192, 512, 마스커블 512, 아이폰용 180) |

## 중요: 파일을 더블클릭해서는 설치되지 않습니다

설치 기능과 서비스 워커는 **https 주소**에서만 동작합니다. 아래 방법 중 하나로 인터넷에 올려 주세요.

## 방법 1. Netlify Drop (가장 쉬움, 약 1분)

1. https://app.netlify.com/drop 에 접속합니다.
2. `seat-pwa` 폴더를 통째로 화면에 끌어다 놓습니다.
3. `https://무작위이름.netlify.app` 주소가 바로 생깁니다.
4. 무료 계정으로 로그인하면 주소가 유지되고, 이름도 바꿀 수 있습니다. 로그인하지 않으면 잠시 뒤 사라질 수 있습니다.

## 방법 2. GitHub Pages (무료, 오래 유지)

1. https://github.com 에 가입하고 새 저장소(New repository)를 만듭니다. 예: `seat-pwa`, Public
2. 저장소 화면에서 **Add file → Upload files**를 누르고, `seat-pwa` 폴더 **안의** 파일과 `icons` 폴더를 모두 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
3. **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://아이디.github.io/seat-pwa/` 주소로 열립니다.

## 휴대폰에 설치하기

- **안드로이드 (크롬)**: 주소를 연 뒤 주소창 옆 설치 아이콘이나 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰 (사파리)**: 주소를 연 뒤 공유 버튼(□↑) → **홈 화면에 추가**
- **PC (크롬·엣지)**: 주소창 오른쪽의 설치 아이콘

## 고친 뒤 다시 올릴 때

`index.html`을 고쳤다면 `sw.js` 맨 위의 `const VERSION = "v1";`을 `"v2"`처럼 올린 뒤 다시 올려 주세요. 그래야 이미 설치한 기기에도 새 버전이 반영됩니다.

## 실시간 저장 (Firebase)

- 예약, 출석 체크, 지각, 예약 열기, 전자출결 기록이 Firebase Firestore(`seat-pwa` 프로젝트)에 저장되어 모든 기기가 같은 화면을 봅니다.
- 날짜별로 따로 저장됩니다: `days/2026-10-03/periods/1` … `/10`. 다음 날이 되면 빈 상태로 시작합니다.
- 화면 맨 아래에 **실시간 연결됨**이 보이면 정상입니다. 인터넷이 끊기면 그 기기에만 저장하는 모드로 동작합니다.
- 관리자 탭에서 **오늘 데이터를 예시로 채우기 / 모두 비우기**, **예시 학생 자동 응답 켜기·끄기**를 할 수 있습니다. 실제 시험 운영 때는 자동 응답을 꺼 주세요.
- 전자출결 자동 시작은 그 시각에 **앱을 열어 둔 기기가 하나라도 있어야** 동작합니다(교수 PC를 켜 두면 됩니다). 아무도 열지 않아도 자동으로 돌게 하려면 Firebase Cloud Functions(유료 Blaze 요금제)가 필요합니다.

### ⚠️ 보안 규칙 (테스트 모드는 30일 뒤 만료)

지금은 테스트 모드라 주소를 아는 누구나 읽고 쓸 수 있습니다. 30일이 지나면 저장이 막히고 화면에 `permission-denied` 오류가 뜹니다.
실제 학생 정보를 넣기 전에 **로그인 기능 + 보안 규칙**을 설정해야 합니다. 그 전까지 시연만 연장하려면 Firebase 콘솔 → Firestore Database → **규칙**에서 날짜를 늘리면 됩니다.
